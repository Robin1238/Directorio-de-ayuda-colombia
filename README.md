# Directorio-de-ayuda-colombia

> Este sitio INTENTA reunir la mayor cantidad de sitios web que la comunidad ha creado para coordinar ayuda tras el terremoto del 10 de agosto de 2026
> No reemplaza a Cruz Roja, Bomberos ni UNGRD - es un puente entre iniciativas ciudadanas que están dispersas en muchos dominios distintos.

## Si quieres colaborar con la lista?

Te pido 2 cosas:

1. Revisa que el sitio web se encuentre activo
2. Manten la informacion lo mas simple y entendible posible (Es una emergencia necesitamos agilidad)

> Si no sabes cómo publicar el cambio, la forma más simple es enviar los cinco datos de arriba (nombre, descripción, url, ciudad, tipo)

## Este directorio

No decide cuál sitio es mejor: solo enlaza los ya existente. La exactitud y disponibilidad de cada sitio depende de quien lo creó.

> Prioriza lo esencial: nombre, ciudad, tipo y el link. Nada que añada pasos de más para alguien que necesita ayuda con urgencia.

### Aviso

La creacion de este sitio fue apoyada con la ayuda de Inteligencia Artificial, a partir de una lista recopilada y revisada MANUALMENTE. No es un desarrollo completo desde cero. Son herramientas que sirven para agilizar el trabajo y eso es exactamente lo que hice.

Lo aclaro por transparencia con quien revise el proyecto o quiera aportar. No me interesa abrir un debate sobre si debería o no usar Inteligencia Artificial, ni recibir sermones sobre su uso. En una emergencia, prefiero usar las herramientas disponibles para hacer algo útil que perder tiempo justificando si las uso.
